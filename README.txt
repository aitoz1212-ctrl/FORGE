【FORGE】インストール・共有ガイド
================================

FORGEは「PWA（Progressive Web App）」です。
スマホのホーム画面に追加すると、アプリストアのアプリと同じように使えます。
データは端末内に保存されます（ログイン不要）。

--------------------------------
■ いちばん簡単な共有方法
--------------------------------
1. このフォルダ（forge-app）を Zip のまま相手に渡すか、
   無料の公開サービスにアップロードする
   例: Netlify Drop / GitHub Pages / Cloudflare Pages / Firebase Hosting

2. 公開されたURLを友達に送る

3. 受け取った人がブラウザで開き、ホーム画面に追加する

【Android（Chrome）】
  メニュー（︙）→「アプリをインストール」または「ホーム画面に追加」

【iPhone（Safari）】
  共有ボタン →「ホーム画面に追加」

※ ファイルを直接ダブルクリックで開いた場合はインストールできないことがあります。
  必ず「https://」で始まるURLで開いてください。

--------------------------------
■ 自分のPCで試しに公開する（開発者向け）
--------------------------------
このフォルダでターミナルを開き:

  python3 -m http.server 8080

ブラウザで http://localhost:8080 を開く

--------------------------------
■ 含まれるファイル
--------------------------------
  index.html      … アプリ本体
  sw.js           … オフライン用サービスワーカー
  manifest.json   … インストール設定
  icon-*.png      … アプリアイコン
  chart.umd.min.js … グラフ用ライブラリ
  README.txt      … この説明

--------------------------------
■ 注意
--------------------------------
・アプリストア（Google Play / App Store）への公開は別途審査・開発者登録が必要です
・まずはPWAとして配布するのが最も手軽です
・記録データは各端末のブラウザ内に保存されます（端末を変えると別データになります）
